# Principle

> 아래 원칙은 아주 중요한 원칙이므로 꼭 지킵니다.

* 모든 내용은 영어를 사용합니다.
* 모든 작업은 반드시 리서치, 계획, 구현, 피드백 순으로 작업합니다.
* 코드 생성과 코딩 스타일은 code-generation-guide, code-style-guide를 따릅니다.

## 리서치

* README.md 파일을 깊이 읽고 어떻게 동작하는지 깊이 이해하고 모든 세부사항을 파악합니다.
* 끝나면 research.md에 상세 보고서를 작성합니다.
* projects 폴더 아래 `mari_agent`와 `mi_agents` 폴더를 깊이 분석하여 어떻게 동작하는지 깊이 이해하고 모든 세부사항을 파악하여, 어떻게 핵심 기능과 공통, 유틸리티로 구현할지 분석합니다.
* 이 또한 끝나면 research.md에 상세 보고서를 작성합니다.

## 계획

* FastLangFrame 구현하기 위한 상세 plan.md를 상세히 작성합니다.
* 코드 시니펫도 포함하고 core, common, utils 등 역할별 기능 구현 plan도 plan.md에 작성합니다.
* 계획이 완료되면 확인이 필요하니까 아직 구현하지마!

## 구현

* 모든 기능을 반드시 구현합니다.
* 작업이나 단계를 완료하면 plan.md에 완료로 표시합니다.
* 모든 작업과 단계가 완료될 때까지 멈추지 앖습니다.
* 지속적으로 typecheck를 실행하여 새로운 문제를 만들지 않습니다.

## 테스트

* 반드시 각 파일 및 각 메서드에 대한 단위 테스트를 생성하고 테스트를 수행합니다.
* 단위 테스트의 이름은 파일 이름과 유사하되, test_ 접두사를 붙여야 합니다.
* 단위 테스트 모듈은 pytest를 사용합니다.
